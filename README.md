## Feature

`autorepair`
- [x] 自动将背包内的带有经验修补且耐久为满的物品替换到副手
- [ ] 自动为装备附魔经验修补 

`autodrop`
- [ ] 过滤背包物品，钓鱼佬专用

`autocommand`
- [ ] 当玩家在某个世界时，自动执行指定命令，例如在大厅服时，切换到生存服（配合自动重连模组使用）(拾玖世界害人不浅啊)

`highlightBox`
- [ ] 高亮实体
- [ ] 自定义要高亮的实体
