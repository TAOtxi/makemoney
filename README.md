## Feature

`autorepair`    `# 有bug，没测试完`
- [x] 自动将背包内的带有经验修补且耐久为满的物品替换到副手
- [x] 自动为装备附魔经验修补

`autodrop`
<br>自动检查背包内是否有不需要的物品。当玩家潜行、打开背包或者打开配置界面时，将跳过检查。
- [x] 过滤背包物品，钓鱼佬专用
- [x] 白名单可配置标签、id以及附魔等物品信息
- [x] 指定要过滤的物品（黑名单）
- [x] 可用正则匹配
- [ ] 在捡到物品的事件中，调用丢弃方法

命令
```
/autodrop reload        # 重新加载配置文件
/autodrop true          # 开启此功能
/autodrop false         # 关闭此功能
/autodrop config        # 打开配置界面
```
