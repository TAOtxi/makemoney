## Feature

`autorepair`
- [x] 自动将背包内的带有经验修补且耐久为满的物品替换到副手
- [x] 自动为装备附魔经验修补

`autodrop`
- [x] 过滤背包物品，钓鱼佬专用
- [x] 白名单可配置标签、id以及附魔等物品信息
- [x] 指定要过滤的物品（黑名单）

`autocommand`
- [x] 当玩家在某个世界时，自动执行指定命令，例如在大厅服时，切换到生存服（配合自动重连模组使用）唉 `#待测试`

`highlightBox`
- [x] 高亮实体 `#待测试`
- [x] 自定义要高亮的实体 `#待测试`
